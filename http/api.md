# Que es una API?
Es un conjunto de reglas que define el servidor. Esto nos permite intercambiar informacion entre el servidor y el cliente (la app) donde el servidor define lo que quiere compartir y como

**ejemplo**

```bash
curl https://jsonplaceholder.typicode.com/users/1

```

Esta url le pide al servidor de "jsonplaceholder" por informacion del usuario 1. Luego este lo prepara en formato JSON y lo devuelve.
